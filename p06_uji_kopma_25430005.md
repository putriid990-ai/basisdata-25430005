## Latihan E (Kopma)

### Latihan 1: Pengarsipan anggota nonaktif sebelum 2025

Anggota yang masih punya penjualan tidak boleh ikut terhapus (A-0302 punya nota PJ-2609-0131; A-0301 tidak punya nota).

```sql
DROP TABLE IF EXISTS anggota_arsip;
CREATE TABLE anggota_arsip LIKE anggota;

INSERT INTO anggota_arsip
SELECT * FROM anggota
WHERE status_anggota = 'nonaktif'
  AND tgl_daftar_anggota < '2025-01-01'
  AND id_anggota NOT IN (SELECT id_anggota FROM penjualan WHERE id_anggota IS NOT NULL);

DELETE FROM anggota
WHERE id_anggota IN (SELECT id_anggota FROM anggota_arsip);

SELECT no_anggota, status_anggota FROM anggota_arsip;   -- harapan: A-0301
SELECT no_anggota, status_anggota FROM anggota;         -- harapan: A-0302 tetap ada
```

Hasil nyata: A-0301 (nonaktif, tanpa nota) berpindah ke `anggota_arsip`; A-0302 (punya nota PJ-2609-0131) tetap berada di tabel `anggota`.

### Latihan 2: Naikkan harga makanan 5% dibulatkan ke ratusan terdekat

```sql
UPDATE barang
SET harga_jual_barang = ROUND(harga_jual_barang * 1.05, -2)

SELECT kode_barang, harga_jual_barang FROM barang WHERE kategori_barang = 'makanan';
```
